# Acorn Economic Network

The economic network observes the real cognitive network without confusing identity, connection, execution, verification or payment.

`CONNECTION -> IDENTITY -> ADMISSION -> EXECUTION -> VERIFICATION -> USAGE -> ACCOUNT -> PRICING -> BILLING CANDIDATE`

A declared identity is not a connection. A connection is not usage. Usage is not a charge. A billing candidate is not a payment.

Routine connections remain silent. Unknown or unauthorized identities are quarantined/denied without inventing identity. Repairable runtime problems remain inside the autonomous correction loop. Carl is interrupted only at a real human boundary such as authorization, secrets, pricing decision, payment, or merge.

Existing connected intelligences and future intelligences follow the same measured path: only real executed and verified work can become commercial usage. Pricing is explicit and versioned. The network never fingerprints users, performs hidden tracking, guesses identity, auto-charges, or attempts payment.
