# Croissance — développeurs et utilisateurs

Deux publics, deux portes, une carte.
Compteur : `uses: carllaliberte/unforge-check` et exports `registre.json`.
Pas le nombre d’hôtes grok.me.

## Porte développeurs

```bash
git clone https://github.com/carllaliberte/unforge-check
cd unforge-check
pip install -r requirements.txt
python3 check.py examples/bienvenue.txt examples/bienvenue.txt.unforge.json
```

```yaml
- uses: carllaliberte/unforge-check@main
  with:
    file: docs/contrat.pdf
    proof: docs/contrat.pdf.unforge.json
```

Manque encore : paquet PyPI, topics GitHub, lien sortant depuis la carte.
