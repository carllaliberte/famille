# Lancement — checklist typée

Hôte preview. Pas un SaaS. On ne coche pas de fausses cases.

## On fait

- HTTPS : déjà grok.me. Pas de secret, pas de clé QUANTUM, pas de token dans le repo.
- Pages `#/legal` `#/404` `#/lancement`
- Meta + Open Graph : Famille · the map, not a rail · not a chain · not money
- robots.txt autorise `/` ; sitemap des routes hash utiles en note
- Smoke : Inscrire · Juger · Exporter ; ε=0 deny ; cents deny ; badge PREVIEW
- Mobile first, FR/EN
- Rollback : republish le remix précédent. Git reste la vérité des docs.

## On ne fait pas sur cet hôte

Comptes, RBAC, paiement, e-mails transactionnels, base à indexer,
cookie banner sans cookie, Google Analytics, Sentry obligatoire,
DNS perso tant que le slug grok.me tient.

Loi 25 / confidentialité : page courte. On n’envoie rien.
Le juge tourne ici. Le sceau, ailleurs.
