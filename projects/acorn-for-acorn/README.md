# ACORN FOR ACORN — FIRST MEGA PROJECT

**The first customer of Acorn is Acorn itself.**

This is not a demo and not a second product. It is the canonical internal reference project that uses Acorn's own universal fabrics to make Acorn complete, measurable, commercially usable, operationally observable and continuously improvable.

## Mission

Build the complete Acorn experience as if an external customer had commissioned it:

**INTENT → DISCOVER → ARCHITECT → COMPOSE → BUILD → TEST → FALSIFY → MEASURE → VERIFY → DELIVER → OPERATE → BENCHMARK → OPTIMIZE → REUSE → RECOMPOSE**

## Workstreams

1. Product: a customer can understand what Acorn does and request a result.
2. Intake: human intent becomes a structured project.
3. Capability: every required capability is discovered, qualified and routed.
4. Intelligence: provider-neutral intelligences cooperate through adapters.
5. Connection: real external surfaces are discovered and truth-state tracked.
6. Execution: tasks execute only through authorized paths.
7. Evidence: every consequential claim has provenance, measurement and expiry.
8. Quality: every deliverable is benchmarked against explicit acceptance criteria.
9. Security: least privilege, fail-closed boundaries and replay safety.
10. Economics: cost, value, margin and commercial states remain measurable.
11. Operations: failures diagnose, retry, substitute, recompose or escalate.
12. Learning: verified outcomes become reusable capability candidates.
13. Evolution: the project continuously searches for measured improvements.
14. Real world: LIVE is only declared from actual observed evidence.

## Definition of done

The project is not "done" because files exist.

It becomes deliverable only when its declared acceptance criteria are satisfied with evidence. Its optimization state remains open forever:

**OBSERVE → BENCHMARK → IMPROVE → VERIFY → ADOPT → OBSERVE**

## Sovereignty

Acorn can discover, reason, compose, simulate, build, test and propose.

Carl remains the authority for merge and other consequential protected actions.

**CAPABILITY ≠ AUTHORITY.**
