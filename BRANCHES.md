# Branches

```
ville/<quartier>-<piece>
```

Quartiers : `juge` `preview` `conso` `rente` `garde`

Exemples :
- `ville/juge-cli-schema`
- `ville/preview-badge`
- `ville/conso-action`
- `ville/rente-recu`

Titre PR : `Ville <quartier> — <pièce>`
1 branche à la fois par repo. Squash. Ne pas renommer l'historique A–N / bloc/*.
