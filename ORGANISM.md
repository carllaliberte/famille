# ACORN ORGANISM

Métaphore d’architecture. Pas un être vivant. Pas une conscience. Pas une volonté. Pas un oracle.

## Ce que c’est

Carte des **organes déjà présents** dans FAMILLE, plus quelques adaptateurs minces là où l’audit a trouvé un trou réel.

## Ce que ce n’est pas

- une IA unique
- un cerveau central
- un second mesh
- un second mode cognitif
- `consciousness: true`
- LIVE
- FULL SWARM CONNECTED

## Organes → existant

| Organe | Responsabilité | Où c’est déjà |
|---|---|---|
| Cœur | constitution, invariants, souveraineté | `AGENTS.md` · FILE.md · CHARTE si présent |
| Cerveau | COLLECTIVE_COGNITION | `COGNITION.md` · `schema/cognition.v0.json` · `cognition.mjs` |
| Nerf | signaux, synapses, routage | `NERVE.md` · `schema/nerve.v0.json` · `sdk/nerve.js` |
| Perception | qualifier une entrée | `sdk/organism.js` `perceive` (nouveau, mince) |
| Métabolisme | coût / dispo **si mesuré** | `sdk/organism.js` `resource` — jamais inventé |
| Immunité | anomalie = alerte, pas verdict | dérives `COGNITION.md` + `classifyAnomaly` |
| Squelette | contrats versionnés | `schema/*.v0.json` intouchés |
| Organes spécialisés | mesure, garde, juge, ots… | autres repos / protocoles — pas recentrés ici |
| Régénération | évolution datée, pas « mieux » | `evolve` |
| Environnement | externe ≠ fiable | `INTEROP-IA.md` |
| Homéostasie | état **décomposable** | `healthState` — pas un score unique |

PERCEIVE → SIGNAL → ROUTE → THINK → CHALLENGE → EVIDENCE → MEASURE → REMEMBER → DECIDE → ACT → OBSERVE → LEARN → ADAPT → REASSESS → ∞

∞ = horizon ouvert. Pas immortalité. Pas autonomie sans humain.
