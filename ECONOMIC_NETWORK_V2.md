# Acorn Economic Network v2

The economic network is one continuous measured path:

`connection -> identity -> admission -> execution -> verification -> usage -> account -> pricing -> billing boundary`

Connection is not usage. Usage is not a charge. A billing candidate is not payment.

Routine events stay inside the autonomous runtime. Unknown or unauthorized actors are controlled without identity guessing. Existing and future intelligences enter the same usage ledger only after real execution and verification.

Pricing is explicit and versioned. Automatic charging and payment attempts remain disabled. Carl remains the human authority for payment, secrets, authorization, pricing decisions and merge.
