# ACORN — Visionary Quality Constitution

Acorn must remain credible for decades, not merely impressive at one release.

This benchmark translates documented operating principles associated with major builders into measurable Acorn quality dimensions. It is not a ranking of people and does not import their authority, personality or decisions into Acorn.

## Benchmark families

- Apple / Steve Jobs — product craft, simplicity, human experience, end-to-end coherence.
- Amazon / Jeff Bezos — customer obsession, long-term thinking, invention, measurement, operational excellence.
- SpaceX/Tesla / Elon Musk — first-principles reasoning, physical execution, iteration and difficult systems.
- NVIDIA / Jensen Huang — full-stack platform leverage, ecosystem, compute and developer enablement.
- Microsoft / Bill Gates — software platforms, distribution, standards and developer leverage.
- Microsoft / Satya Nadella — learning, cloud platforms, partnerships and adaptability.
- Google / Larry Page & Sergey Brin — information infrastructure, experimentation, scale and broad primitives.
- Meta / Mark Zuckerberg — identity, networks, platform participation and global-scale ecosystem effects.

No single person or company is the template.

## Quality bar

customer_value + human_experience + product_craft + simplicity + first_principles + real_world_execution + platform_leverage + ecosystem + interoperability + developer_enablement + learning + experimentation + operational_excellence + security + resilience + evidence + provenance + long_term_durability + economic_durability + human_authority

A project can be technically correct and still fail one or more dimensions.

## Long-term credibility rules

1. Evidence expires; there is no permanent certification.
2. Labels require dated evidence.
3. Visionary principles are benchmarks, not proof.
4. Happy-path-only testing is insufficient.
5. Customer outcomes and real-world behavior matter alongside technical correctness.
6. Material changes trigger remeasurement.
7. Provider neutrality and replaceability are quality properties.
8. Failure and degraded-state behavior are tested.
9. Economics are measured only from observed facts.
10. Every Acorn-engineered artifact should carry traceable provenance.

## Required lifecycle

INTAKE → ARCHITECT → COMPOSE → BUILD → TEST → FALSIFY → MEASURE → VERIFY → TRACE → OFFER/DELIVER → MONITOR → REASSESS

CODE_PRESENT != TESTED != EXECUTED != MEASURED != VERIFIED != LIVE

CAPABILITY != AUTHORITY

CARL = MERGE
