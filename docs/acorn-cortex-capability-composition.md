# Acorn Cortex — Adaptive Capability Composition

Contract: `acorn.cortex-capability-composition.v1`

The Cortex can now compose a temporary cognitive team from available intelligences according to the capabilities required by a goal.

Flow:

`goal → required capabilities → provider-neutral routes → coverage/gaps → team selection → cognitive plan`

Properties:
- multiple intelligences can be composed for one mission;
- providers are metadata, not privileged classes;
- missing capabilities become explicit gaps;
- no invented coverage;
- team selection remains separate from authorization;
- planning never executes external effects;
- authority remains human/governed;
- no Breaker access.

This fabric composes existing adapters; it does not create a second runtime or second authority source.
