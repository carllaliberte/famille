# ACORN — Universal World Engine

## Purpose

One large convergence fabric over the existing Acorn system. It is not a new authority layer, payment engine, marketplace, evidence registry or second runtime.

It connects the already-built fabrics into one measurable cycle:

**INTENT → WORLD → DEMAND ↔ CAPABILITY → COMPOSE → SIMULATE → QUALIFY → OFFER → ORDER → AUTHORIZE → EXECUTE → VERIFY → DELIVER → VALUE → BENCHMARK → LEARN → REGISTER → REUSE → PRODUCTIZE → OPPORTUNITY → RECOMPOSE → WORLD**

## What changes

Acorn treats every customer request, internal objective, developer need and real-world project as an intent that can be compiled into tasks and matched against measured capabilities.

Capabilities can be software, AI models, people, organizations, data, compute, connectors, machines, robots, suppliers, energy, services or future systems.

A result is not promoted merely because it exists. It must be measured, evidenced and verified before it can become reusable capability.

## Commercial reality

OFFER ≠ ORDER ≠ PAYMENT ≠ EXECUTION ≠ VALUE.

A payment observation may authorize a commercial state through the existing server controls, but it does not prove that work happened or that customer value was produced.

## Continuous compounding

PROJECT → OUTCOME → EVIDENCE → CAPABILITY → REUSE → PRODUCT → OPPORTUNITY → PROJECT.

This is the compounding mechanism: successful reality creates reusable assets without granting the system autonomous authority.

## Human sovereignty

Acorn may discover, compare, compose, simulate, propose, build and measure. Existing authority gates remain responsible for consequential effects.

No automatic merge, spending, contract, signing, deletion or publication is introduced.

## Best-known result

Selection is always scoped to explicit comparable candidates and evidence. It does not claim a universal global optimum.

## Truth

UNKNOWN remains UNKNOWN. Expired evidence returns to observation. SIMULATED is never EXECUTED. CODE_PRESENT is never LIVE by itself. VERIFICATION requires evidence and measurement.
