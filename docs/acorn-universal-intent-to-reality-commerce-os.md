# ACORN — UNIVERSAL INTENT → REALITY COMMERCE OS

The customer-facing convergence of Acorn.

## Customer loop
DISCOVER → INTAKE → UNDERSTAND → QUALIFY → DECOMPOSE → DISCOVER CAPABILITIES → COMPOSE → SIMULATE → ESTIMATE → BENCHMARK → PACKAGE → OFFER → CHECKOUT → ORDER → PAYMENT OBSERVED → AUTHORIZE → EXECUTE → OBSERVE → VERIFY → DELIVER → MEASURE VALUE → RENEW → EXPAND → LEARN → REUSE → RECOMPOSE.

## Product principle

The customer does not need to understand Acorn's internal architecture. The customer provides an objective and constraints; Acorn compiles them into a measurable project and returns an outcome with evidence.

## Economic truth

OFFER ≠ ORDER ≠ PAYMENT_OBSERVED ≠ EXECUTION_AUTHORIZED ≠ EXECUTION ≠ DELIVERY ≠ CUSTOMER_VALUE.

Revenue is not customer value. Payment is not execution. Delivery is not proof of value without measurement.

## Compounding

A measured verified outcome can produce a renewal/expansion candidate and reusable assets for future projects.

## Authority

Price changes, refunds, payouts, contracts, signing, deletion, publication, production and merge remain human/server authorized.
