# ACORN — CORTEX OPERATING SYSTEM
Acorn's cortex is the continuous coordination layer for the environment.

It does not attempt to become the owner or governor of the environment. It continuously turns signals into structured knowledge, connects knowledge to capabilities, composes plans, measures outcomes and learns from verified results.

## Continuous loop
OBSERVE → PROVENANCE → QUALIFY → CONNECT → DISCOVER → COMPOSE → VALIDATE → AUTHORIZE → EXECUTE → MEASURE → LEARN → REUSE → OBSERVE.

## What the cortex knows
Needs, knowledge, capabilities, outcomes, risks, opportunities, constraints and resources are first-class signals.

## What makes it fluid
A need can be matched simultaneously against environmental knowledge and available capabilities. Related signals form a graph, allowing useful context to travel without requiring every intelligence or organization to use the same model, provider or API.

## What makes it improve itself
Acorn compares measured outcomes against prior outcomes using explicit optimization dimensions. Successful patterns become reusable learning. No unmeasured hypothesis is promoted to truth.

## Truth
PROPOSED ≠ OBSERVED ≠ MEASURED ≠ VERIFIED ≠ LIVE.

Expiry and revocation remain visible. Provenance travels with knowledge.

## Constitutional boundary
Self-optimization never grants authority. No hidden learning, automatic spending, signing or merging is allowed. Breaker remains untouched.

**CAPABILITY ≠ AUTHORITY.**

The result is a cortex-like coordination fabric: distributed cognition can become more fluid and more knowledgeable while individual humans, organizations and intelligences retain their own authority.
