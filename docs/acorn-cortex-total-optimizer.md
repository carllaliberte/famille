# ACORN — CORTEX TOTAL OPTIMIZER

This module is the convergence point for the existing Acorn fabrics. It does not create a new cognitive authority; it coordinates the evidence and optimization loops already established.

## One adaptive cycle
OBSERVE → UNDERSTAND → CONNECT → DISCOVER → COMPOSE → SIMULATE → EXECUTE → MEASURE → COMPARE → LEARN → OPTIMIZE → REUSE.

The cortex evaluates the environment by combining:
- shared provenance-first knowledge;
- qualified participants and capabilities;
- capability offers and failover routes;
- declared multi-objective goals;
- measured outcomes and costs.

## What "good for Acorn" means

Acorn does not assume that bigger, newer, faster, cheaper or more autonomous is better. "Good" is determined against explicit objectives and measured outcomes. A candidate that improves one dimension while damaging another is visible as a trade-off rather than silently accepted.

## Knowledge fluidity

Knowledge is routed by need and confidence, connected into a graph, and allowed to expire. Insights remain provisional until validated. Successful optimization outcomes become reusable learning.

## Cortex vs authority

The cortex coordinates the ecosystem; it does not own it. It may discover, compare, propose, simulate and learn. Consequential actions remain explicitly authorized.
