# ACORN Organism Completion
Contract: `acorn.organism-completion.v1`

This integration closes the nine major architectural organs identified after Cortex, World Model, Dynamic Synaptic Fabric and Cognitive Metabolism:
1. SELF_MODEL — self-knowledge, limits and uncertainty
2. EXPERIMENT — simulation, hypotheses and prediction testing
3. ECOSYSTEM — provider-neutral intelligences, tools and connectors
4. CAPABILITY_EVOLUTION — measured capability revision/versioning
5. COLLECTIVE — coalition, consensus and dissent
6. TEMPORAL — prediction, horizon and expiration
7. ACTION_FACTORY — governed real-world project planning
8. VALUE — measured cost, value and margin
9. RESILIENCE — failure recovery and continuity

The integration deliberately does not create a second Cortex, router, memory, economy, execution engine or authority system. Existing Cortex, World Model, Synaptic Fabric, Metabolism, Effect Governor and Execution Fabric remain canonical.

Cycle:
**PERCEIVE → SELF-MODEL → DISCOVER → EXPERIMENT → COMPOSE → PLAN → AUTHORIZE → ACT → OBSERVE → MEASURE → VERIFY → LEARN → OPTIMIZE → EVOLVE → RECOVER → REOBSERVE**

Truth boundaries:
**CAPABILITY ≠ AUTHORITY**
**PREDICTION ≠ FACT**
**LEARNING ≠ AUTHORIZATION**
**OPTIMIZATION ≠ SPENDING**
**DEFINED ≠ EXECUTED ≠ MEASURED ≠ LIVE VERIFIED**

No auto-authorize, auto-spend, auto-contract, auto-sign, auto-merge or hidden external effect. Learning and optimization require measured, verified outcomes.
