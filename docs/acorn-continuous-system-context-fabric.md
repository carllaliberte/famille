# ACORN CONTINUOUS SYSTEM CONTEXT FABRIC
Contract: acorn.continuous-system-context-fabric.v1

Creates a shared, time-bounded system context from the semantic event spine, world model, reality observations, outcomes and resources.

Properties:
- current-state projection from history;
- freshness and staleness;
- contradiction exposure;
- task-scoped context selection;
- context reconciliation;
- measurable context deltas;
- one shared context bridge for existing organs.

Architecture:
EVENT SPINE + WORLD MODEL + REALITY + OUTCOMES + RESOURCES
→ CONTINUOUS SYSTEM CONTEXT
→ CORTEX / MEMORY / CAPABILITY / PLANNING / OBSERVATION
→ NEW EVENTS

Context is not truth, freshness is not verification, and structural context is not LIVE proof.
No second memory, authority, execution runtime or Governor.
