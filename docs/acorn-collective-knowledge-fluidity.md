# ACORN — COLLECTIVE KNOWLEDGE & FLUIDITY

Les certitudes ont une date de fin.

This file describes a local rail. It is not a receipt. It is not LIVE. It is not `claim.v0`.

## Principle

ONE NODE LEARNS → EVIDENCE IS CAPTURED → RESULT IS MEASURED → KNOWLEDGE IS VERIFIED → KNOWLEDGE BECOMES REUSABLE → OTHER NODES BENEFIT → NEW RESULTS RETURN TO THE NETWORK.

These are functions. They are not a live run. `verifyKnowledge` is a local gate. It does not execute, spend, merge, or sign.

Knowledge is not copied as an unquestioned truth. Provenance, scope, evidence, confidence and temporal validity travel with it.

## Evidence gate

`verifyKnowledge` stays `PROPOSED`/`OBSERVED` unless evidence tokens are present. Empty evidence throws `EVIDENCE_REQUIRED`. A local `VERIFIED` state is still not EXECUTED, not MEASURED, not LIVE VERIFIED.

The object `id` is FNV-1a 32 (`id_algo: fnv1a-32`). That fingerprint is not SHA-256 and not `claim.v0` `evidence_hash`. LU still needs the hash of the content actually read. This rail does not mint that hash.

## Fluidity

The system routes knowledge and capabilities toward the participant that can use them best within explicit constraints. Duplicate verified knowledge is deduplicated; conflicting claims remain visible instead of being silently averaged away.

## Collective intelligence

Local experience can become a network-level reusable asset only after evidence gates. Expiry and revocation are first-class states. Reuse is a hypothesis. It still requires measurement.

## Constitutional boundary

Knowledge never grants authority. No automatic merge, spend, signature or Breaker access is introduced. `assertCollectiveKnowledgeConstitution` without a snapshot throws. Flags are not optional.
