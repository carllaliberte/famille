# ACORN — COLLECTIVE KNOWLEDGE & FLUIDITY
Acorn treats knowledge as a temporal, provenance-preserving network resource.

## Principle
ONE NODE LEARNS → EVIDENCE IS CAPTURED → RESULT IS MEASURED → KNOWLEDGE IS VERIFIED → KNOWLEDGE BECOMES REUSABLE → OTHER NODES BENEFIT → NEW RESULTS RETURN TO THE NETWORK.

Knowledge is not copied as an unquestioned truth. Provenance, scope, evidence, confidence and temporal validity travel with it.

## Fluidity
The system routes knowledge and capabilities toward the participant that can use them best within explicit constraints. Duplicate verified knowledge is deduplicated; conflicting claims remain visible instead of being silently averaged away.

## Collective intelligence
Local experience can become a network-level reusable asset only after evidence gates. Expiry and revocation are first-class states.

## Constitutional boundary
Knowledge never grants authority. No automatic merge, spend, signature or Breaker access is introduced.

## Parabolic loop
Every verified outcome can reduce future search, improve composition, avoid repeated mistakes and increase the value of every subsequent project.
