# ACORN — MEGA CONVERGENCE

All currently open legacy work is audited together. Useful intent is recovered onto current MAIN; stale branches are never treated as merge-ready merely because they contain useful code.

Sources include the current open evolution, security/reliability, market/value and older real-world/runtime work.

Canonical cycle:

AUDIT MAIN → AUDIT OPEN WORK → RECOVER USEFUL WORK → RECONCILE → SECURE → MEASURE → VERIFY → DELIVER → BENCHMARK → OPTIMIZE → REOBSERVE

The convergence does not create a second authority or runtime. It preserves the existing Acorn fabrics and their truth boundaries.

**CAPABILITY ≠ AUTHORITY.**

No automatic merge, spending, contracting, signing, deletion or publication.
