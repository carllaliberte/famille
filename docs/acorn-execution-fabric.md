# ACORN Execution Fabric

The execution fabric is the operational bridge between an enterprise plan and measurable work.

Flow:

`PLAN → DEPENDENCIES → READY → HUMAN AUTHORIZATION → RUN → EVIDENCE → VERIFY → COMPLETE`

Properties:
- provider-neutral task graph;
- capability routing remains separate from authority;
- resumable task state and dependency checks;
- explicit execution events;
- synthetic end-to-end execution for regression proof;
- no automatic contract, spend, transfer, custody, signing, publishing, outreach or merge.

A task may be proposed by an intelligence or connector, but consequential execution remains explicitly authorized by the human authority.

The fabric does not claim external execution merely because a task is represented internally. External execution requires connector evidence and a measured result.
