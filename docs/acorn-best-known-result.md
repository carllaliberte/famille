# ACORN — Best-Known Result & Adaptive Market Fabric

Acorn continuously adapts to markets, technologies, providers, capabilities and future signals.

This fabric does **not** claim a literal global optimum. It records the strongest measured result within an explicit comparison scope.

## Core law

`INTENTION → REALITY → MEASUREMENT → BEST-KNOWN-IN-SCOPE → CAPABILITY → NEW OPPORTUNITY`

A candidate is comparable only when its relevant metric is measured, evidence exists, the evidence is temporally valid, declared constraints are satisfied, and the candidate has a non-zero expiry horizon.

The selector returns `BEST_KNOWN_IN_SCOPE`, never an unsupported “world best”. A future integration may declare `GLOBAL_MEASURED` only when evidence actually supports that coverage.

## Adaptation

Market, capability and future signals are dated evidence:

`OBSERVE → QUALIFY → COMPARE → PROPOSE → HUMAN AUTHORIZE → EXECUTE → MEASURE`

Consequential actions remain human-gated.

## Compounding

A measured outcome can register a reusable capability carrying provenance, evidence, version, rights, measurement date and expiry:

`RESULT → CAPABILITY → COMPOSITION → NEW RESULT`

## Truth constraints

Measurement is not a claim. Candidate is not execution. Execution is not value. Value is not revenue. Adaptation is not authorization. Capability is not authority. No automatic merge. No expiry-free assurance.

This is a fabric, not a second runtime, market engine or economic engine.
