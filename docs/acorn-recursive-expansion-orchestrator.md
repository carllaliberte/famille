# Recursive Expansion Orchestrator

Contract: `acorn.recursive-expansion-orchestrator.v1`.

This is the next growth multiplier after the Recursive Self-Expansion Engine. It creates a bounded search frontier over existing capabilities and unknown space, deduplicates hypotheses, scores only measured results, allocates an explicit exploration budget, and promotes only measured+verified evidence to reusable expansion.

The frontier can grow combinatorially, but execution remains bounded and governed. The system never treats search-space size as proof of capability.

Constitution: CAPABILITY ≠ AUTHORITY; SEARCH ≠ EXECUTION; SIMULATION ≠ REALITY; MEASURED ≠ VERIFIED; VERIFIED ≠ AUTHORIZED; no automatic promotion, authorization, execution, spend, signing or external effect.
