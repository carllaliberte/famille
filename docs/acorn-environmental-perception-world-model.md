# ACORN Environmental Perception & World Model

Contract: `acorn.environmental-perception-world-model.v1`

This is the first major organ after Cortex closure. It is the canonical sensing/world-model boundary, not a second Cortex.

## Cycle

RECEIVE → NORMALIZE → PROVENANCE → DETECT CONFLICT → MODEL ENTITIES → MODEL RELATIONS → MEASURE COVERAGE → EXPOSE GAPS → REOBSERVE

## Responsibilities

- normalize heterogeneous environmental signals;
- preserve source, observation time, validity and evidence;
- represent people, organizations, projects, services, intelligences, capabilities, resources, events, documents and machines;
- maintain typed relations;
- merge observations without silently erasing conflicts;
- expose missing coverage instead of inventing state;
- provide a provider-neutral substrate for future connectors and physical sensors.

## Boundaries

Perception never grants authority, authorizes an action, performs an external effect or claims LIVE merely because data was received. External effects remain behind the existing execution/effect governance.

## Evolution

New signal adapters must produce normalized observations rather than new parallel state systems. New entity types are additive and tested. New inference must retain provenance and distinguish observed facts from derived hypotheses.

## Truth model

DEFINED ≠ EXECUTED ≠ MEASURED ≠ LIVE VERIFIED.

A passing unit test proves only the tested code path.
