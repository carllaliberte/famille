# ACORN Cognitive Computation Engine

Contract: `acorn.cognitive-computation-engine.v1`

This runtime unifies multi-state hypotheses, probabilistic belief updates, bounded quantum-inspired interference, simulation, computation-strategy routing, measurement and explicit state collapse.

It is deliberately **quantum-inspired**, not a claim of physical quantum computation.

## Canonical loop

INGEST → CONTEXTUALIZE → GENERATE_STATES → INFER → INTERFERE → SIMULATE → ROUTE_COMPUTATION → MEASURE → VERIFY → COLLAPSE → LEARN → REOBSERVE

## Truth model

- probability is not truth;
- simulation is not reality;
- collapse is an algorithmic reduction of a hypothesis space;
- quantum-inspired interference is a bounded scoring transform;
- QPU is a compute resource, not an intelligence;
- physical quantum claims require physical evidence.

## Integration

The engine is intentionally compositional with the existing Context, Event Spine, Capability Mesh, Compute Fabric, Quantum Interop, Digital Twin, Evidence and Governance systems. It does not create a second Cortex, authority system, execution runtime or Breaker.

All consequential execution remains behind existing governance and human authorization.
