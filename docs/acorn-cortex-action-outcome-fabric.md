# Acorn Cortex — Action & Outcome Fabric

This module closes the measurable cognition loop without creating a new authority source.

**CAPABILITY ≠ AUTHORITY.**

It composes the existing execution fabric, evidence registry and universal outcome-learning fabric:

`PROPOSAL → AUTHORIZATION → EXECUTION TRACE → OBSERVATION → MEASUREMENT → LEARNING`

The module never performs an external effect itself. It represents authorization and execution state, records trace events, requires evidence for measured claims, and passes verified outcomes to the existing learning fabric.

## Truth states

`PROPOSED`, `AUTHORIZED`, `DENIED`, `HOLD`, `EXECUTING`, `EXECUTED`, `FAILED`, `OBSERVED`, `MEASURED`, `LEARNED`.

A proposal is never treated as execution. Missing evidence is never treated as measurement.

## Governance

- no authority grant
- no automatic consequential execution
- no Breaker access
- no automatic merge
- learning remains provenance-bearing and re-verifiable
- external effects remain outside this module

The next layers can consume these records through existing adapters rather than creating another execution or memory system.
