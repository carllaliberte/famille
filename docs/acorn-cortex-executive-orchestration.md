# ACORN — CORTEX EXECUTIVE ORCHESTRATION
The collective cortex now converts the measured environment into a continuously refreshed action portfolio.

## Function
OBSERVE → UNDERSTAND → PRIORITIZE → COMPOSE → PROPOSE → AUTHORIZE → EXECUTE → MEASURE → LEARN.

The cortex identifies needs, opportunities, risks, blockers, changes and outcomes; connects them to available capabilities and traceable knowledge; and creates ranked proposals.

## Fluidity
The output is a portfolio rather than a single answer. New evidence can reorder priorities without rewriting history.

## Governance
All consequential execution remains separately authorized. The cortex cannot self-execute, self-sign, self-spend, self-merge, transfer authority or touch Breaker.

## Strategic role
This is the bridge between Acorn's collective memory and its universal capability/value fabric: the cortex understands the environment; the fabric finds and composes the means; the execution layer performs authorized work; measurement teaches the cortex what worked.
