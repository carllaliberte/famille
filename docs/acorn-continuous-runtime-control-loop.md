# ACORN CONTINUOUS RUNTIME CONTROL LOOP
Contract: acorn.continuous-runtime-control-loop.v1

The runtime must not be treated as a one-time activation. This block establishes a repeated evidence cycle:

OBSERVE → INGEST EVIDENCE → ASSESS → COMPARE → DETECT DRIFT → SELECT REOBSERVATION → REQUEST AUTHORIZATION → ACT THROUGH GOVERNANCE → OBSERVE AGAIN

It measures drift rather than assuming stability, and keeps authorization/external effects behind existing governance. Drift is evidence, not a causal explanation; LIVE remains evidence-dependent.
