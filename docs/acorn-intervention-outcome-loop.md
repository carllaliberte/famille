# ACORN INTERVENTION OUTCOME LOOP
Contract: acorn.intervention-outcome-loop.v1

Closes the loop after a governed intervention: capture before/after state, compute measured deltas, verify evidence, compare targets, and produce a bounded learning candidate.

ACT → OBSERVE → MEASURE → VERIFY → COMPARE → RETAIN_OR_REVIEW → LEARN_CANDIDATE → RETEST_OR_REOBSERVE

No automatic adoption, authority escalation or external execution.
