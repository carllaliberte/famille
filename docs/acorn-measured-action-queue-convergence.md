# ACORN MEASURED ACTION QUEUE CONVERGENCE
Contract: acorn.measured-action-queue-convergence.v1

Converges measured interventions with structural critical-path information and resource awareness into a bounded, auditable action queue.

Evidence, structural depth, blast radius, cost and risk inform prioritization. The queue never silently authorizes or executes an action.

MEASURE → RECONCILE → PRIORITIZE → REQUEST AUTHORIZATION → GOVERNED ACTION → OBSERVE → VERIFY → RECONCILE
