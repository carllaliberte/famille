# ACORN SYSTEM TREE — FOREST VIEW

Contract: `acorn.system-tree-forest.v1`

## Purpose

The Self-Auditing System is the observer. This organ turns its measured repository inventory into a navigable **tree of the system**: roots, trunks, branches, organs, dependencies, evidence and gaps.

The tree is descriptive, not authoritative. A declared branch is not automatically an implemented branch. A runtime node is not automatically LIVE. A healthy tree is not assumed to be a finished forest.

## Forest model

`ROOT → TRUNK → ORGAN → CAPABILITY → CONNECTION → EVIDENCE → OUTCOME`

### ROOT
Constitution, governance, human sovereignty, Breaker and merge authority.

### TRUNK
Cortex, nervous system, world model, reality fabric, execution/effect governance, evidence and measurement.

### ORGANS
Perception, memory, synapses, metabolism, immune/adversarial cognition, self-model, experimentation, autonomy, capability mesh, connectivity, project/value/resilience fabrics and other measured architectural modules.

### BRANCHES
Declared architectural contracts and their runtime implementations.

### LEAVES
Exports, tests, workflows, evidence references, connectors and observed outcomes.

## Tree rules

1. One concept has one canonical home.
2. A branch without runtime is marked `DEFINED_ONLY`.
3. A runtime without integration is marked `ORPHAN_RUNTIME`.
4. A runtime without attributable tests is marked `TEST_GAP`.
5. A contract without evidence is not marked verified.
6. LIVE requires physical evidence.
7. Connections are directional and evidence-bearing.
8. No second Cortex, second authority system or hidden execution path.
9. Gaps remain visible instead of being filled by narrative.
10. The tree is recomputed from repository state; it is not hand-maintained as a claim of completion.

## Forest view

The runtime builds:
- canonical roots;
- trunk candidates;
- organ nodes;
- branch nodes;
- leaf nodes;
- parent/child edges;
- orphan nodes;
- disconnected components;
- measured gap counts;
- evidence density;
- governance coverage;
- implementation/test linkage.

The output is a graph snapshot suitable for future visualization, dependency analysis and convergence.

## Constitutional boundary

`authority:false`
`auto_authorize:false`
`auto_execute:false`
`live:false`

The tree describes Acorn. It does not become Acorn's authority.
