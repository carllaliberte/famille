# ACORN — CORTEX SIGNAL NETWORK

The knowledge cortex now has an operational signal layer.

## Nervous-system model
WORLD → SIGNALS → ROUTING → CORRELATION → RESPONSE CANDIDATES → AUTHORIZED ACTION → OUTCOME → LEARNING → BETTER ROUTING.

Signals represent needs, opportunities, capabilities, risks, changes, failures, successes, knowledge, resources, deadlines and measured value.

## Fluidity
The network prioritizes signals according to explicit interests, evidence and urgency. Correlated signals can reveal relationships between demand, capability and risk without hard-coding a single provider or model.

## Learning
Every response can produce an observed outcome. Successful patterns become reusable learning for future routing.

## Governance
Signals inform decisions; they do not execute them. No automatic consequential action, authority escalation, signature, spend, merge or Breaker access.
