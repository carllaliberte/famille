# ACORN MEASURED INTERVENTION PLANNER
Contract: acorn.measured-intervention-planner.v1

Measured gaps, runtime drift and bounded opportunities become explicit intervention candidates.

IDENTIFY → BASELINE → HYPOTHESIZE → SIMULATE → REQUEST AUTHORIZATION → EXECUTE THROUGH EXISTING GOVERNANCE → OBSERVE → MEASURE → VERIFY → RETAIN OR ROLLBACK

Plans require supporting evidence, resource awareness, human authorization and rollback. Plan comparison does not silently choose a consequential action.
