# ACORN LIVE-WORLD ACTIVATION FABRIC

Contract: `acorn.live-world-activation-fabric.v1`

This fabric closes the gap between a declared connector and a measured world connection. It does not create credentials and does not claim LIVE merely because a connector is configured.

## Reality path

WORLD OBSERVATION → ACTIVATION → CONNECTIVITY FABRIC → NERVOUS SYSTEM → CORTEX / BRAIN → EXISTING GOVERNANCE

A connector becomes `LIVE_VERIFIED` only when the evidence records:

- physical observation;
- authentication;
- usability;
- dated evidence.

Anything less remains an explicit observation or gap.

## Responsibilities

- turn external observations into provenance-preserving world signals;
- require the existing Connectivity Fabric to be LIVE_VERIFIED before routing;
- expose connector/capability gaps instead of fabricating readiness;
- feed the existing Nervous System and World Model without creating a second runtime;
- preserve CAPABILITY ≠ AUTHORITY.

## Boundaries

No auto-authorization, auto-execution, auto-spend, auto-contract, secret creation, Breaker bypass, Effect Governor bypass, or hidden LIVE claim.

Outbound effects continue through the existing Effect Governor and Execution Fabric after human authorization.

## Closure criterion

The fabric is structurally complete when measured connector observations can enter Acorn as dated, provenance-preserving signals and every unverified connector remains visible as a gap.
