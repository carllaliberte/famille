# ACORN AUTONOMOUS KNOWLEDGE LOOP

Contract: `acorn.autonomous-knowledge-loop.v1`

This closes an important cognitive loop: once Acorn can observe reality, it can determine what it does not know, formulate bounded observation candidates, score them against information gain/cost/risk, and select the next observation to request.

## Cycle

ASSESS → FIND GAP → BUILD OBSERVATION CANDIDATES → SCORE → SELECT → WAIT FOR OBSERVATION → MEASURE → VERIFY → LEARN → REASSESS

The selection is a deterministic heuristic. It is **not** a claim of global optimality.

## What becomes autonomous

Acorn can autonomously reason about the next useful knowledge acquisition step. It can identify stale evidence, contradictions, missing evidence and unknown state.

## What remains human-controlled

The selected observation is only a plan. The fabric never creates credentials, invokes a connector, spends money, executes an external effect or authorizes itself. Actual observation continues through the existing Connectivity Fabric, Nervous System, Breaker and human authorization boundaries.

## Core principle

**Acorn may decide what it needs to know; it may not grant itself the authority to obtain it.**

CAPABILITY ≠ AUTHORITY.
