# ACORN — CORTEX SIGNAL FABRIC

The Cortex needs a continuous sensory layer. This fabric converts environmental observations into traceable signals that can be correlated, prioritized and supplied to the knowledge, capability, project and self-optimization systems.

## Loop
WORLD → OBSERVE → SIGNAL → QUALIFY → CORRELATE → PRIORITIZE → CONTEXT → PROPOSE → AUTHORIZE → EXECUTE → OUTCOME → LEARN.

## Fluidity
The signal layer is deliberately transport-neutral. Signals can originate from software, connectors, humans, organizations, devices or physical systems. They are normalized into one cognitive representation.

## Cortex behavior
Acorn can continuously maintain a current environmental context and identify changes, needs, opportunities, risks and constraints. This does not mean autonomous authority: responses remain proposals until authorized.

## Learning
Outcomes feed back into the Cortex as provisional learning. Validated knowledge can then improve routing, project composition and self-optimization.

## Invariants
Traceability required. Hidden signals forbidden. Automatic external execution forbidden. Authority cannot be inferred from cognition. Breaker remains untouched.
