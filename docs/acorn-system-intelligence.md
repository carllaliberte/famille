# ACORN SYSTEM INTELLIGENCE
Contract: acorn.system-intelligence.v1

This block turns the measured tree/forest, proof graph, reliability observations and system genome into a bounded system-intelligence view.

## Integrated fabrics
- System Intelligence: structure, proof, reliability, resources, capabilities, measured gaps.
- Causal Dependency: structural edges are not silently promoted to causality; only explicit observed cause/effect observations are marked causal.
- Opportunity Engine: derives bounded opportunities from measured gaps.
- Decision Queue: preserves a human gate and never authorizes or executes.

## Cycle
OBSERVE → MAP → PROVE → MEASURE → UNDERSTAND → TRACE DEPENDENCIES → IDENTIFY GAPS → DERIVE OPPORTUNITIES → QUEUE DECISIONS → HUMAN/MEASURED NEXT STEP → REOBSERVE

## Truth boundaries
- structural graph != causal proof
- prediction != fact
- opportunity != decision
- capability != authority
- model != world
- measured gap != invented completion
- human gate remains authoritative

The engine is deliberately designed to make the next missing work emerge from measured state rather than from a fixed declaration of completion.
