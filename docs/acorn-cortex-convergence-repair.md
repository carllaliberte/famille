# ACORN — CORTEX CONVERGENCE REPAIR
This module is deliberately additive and starts from current main. It normalizes knowledge into one provenance-first substrate and makes the evidence gate explicit: a credential/account presence is not measurement. Missing evidence remains OBSERVED, never silently VERIFIED.

The cortex aggregates signals from participants, capabilities and outcomes into a traceable snapshot. It does not acquire authority.

Repair principle: recover useful semantics from open work without merging stale divergent branches. Main remains the canonical architecture.
