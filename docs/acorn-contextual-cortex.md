# ACORN — CONTEXTUAL CORTEX

The cortex now assembles the smallest useful context for a task, customer, project, environment or capability from distributed knowledge and live signals.

## Purpose
Prevent every intelligence or subsystem from repeatedly rediscovering the same facts, constraints, evidence and lessons.

## Loop
NEED → ASSEMBLE CONTEXT → RANK → COMPRESS → DETECT GAPS → HANDOFF → ACT/PROPOSE → OBSERVE → UPDATE CONTEXT → LEARN.

## Context quality
Context is ranked using confidence, reliability, relevance, expiry and risk. Missing information remains UNKNOWN rather than being invented.

## Handoff
A context package can move between intelligences and organizational participants while preserving provenance, constraints, gaps and state.

## Cortex boundary
Acorn coordinates context; it does not own the participants and context never creates authority.

## Continuous operation
The fabric is designed for repeated refresh so the ecosystem can operate from current measured knowledge rather than stale assumptions.
