# Recursive Capability Genesis

Contract: `acorn.recursive-capability-genesis.v1`.

Recursively turns the unified growth frontier into bounded next-generation capability hypotheses. Reuses the existing growth system instead of creating another mesh.

OBSERVE → FRONTIER → GAPS → GENESIS → RECURSIVE COMPOSITION → BOUND → SIMULATE → TEST → MEASURE → VERIFY → CANDIDATE → REOBSERVE.

Genesis is hypothesis generation, never proof. Adoption and execution remain governed and human-authorized.
