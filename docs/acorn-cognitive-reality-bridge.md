# ACORN COGNITIVE REALITY BRIDGE

Contract: `acorn.cognitive-reality-bridge.v1`

This is the integration closure between the newly activated real-world connectivity and the existing Cognitive Reality Fabric, Environmental World Model and Cortex.

## Canonical path

WORLD → LIVE WORLD ACTIVATION → COGNITIVE REALITY FABRIC → WORLD MODEL → NERVOUS SYSTEM → CORTEX

The bridge does not create a new brain, router, governor or execution runtime. It composes existing fabrics.

## Cognitive behavior

1. Accept a connector observation.
2. Preserve provenance and verification state.
3. Record it in the existing Reality Fabric.
4. Feed the existing Environmental World Model.
5. Expose stale/conflicting/missing information.
6. Require the existing Connectivity Fabric before Cortex routing.
7. Select re-observation when knowledge gaps remain.

The bridge may recommend what to observe next, but it cannot authorize or execute the observation automatically.

## Boundaries

CAPABILITY ≠ AUTHORITY. LIVE remains evidence-bound. Conflicts remain visible. External effects remain behind the existing Effect Governor / Execution Fabric and human authorization.
