# ACORN — PARABOLIC DEVELOPMENT
Parabolic development means maximizing compounding leverage: each verified improvement should make future improvements faster, more reusable, more valuable and more measurable. It is a development strategy, not a guarantee of mathematical growth.
## Flywheel
OBSERVE → DISCOVER → QUALIFY → BUILD → VERIFY → DELIVER → MEASURE → CAPTURE → REUSE → COMPOSE → PRODUCTIZE → DISTRIBUTE → ACQUIRE → DELIVER AGAIN → LEARN → OPTIMIZE → AUTOMATE → SCALE → REOBSERVE.
## Multiplication
ONE BUILD → MANY USES; ONE CAPABILITY → MANY PRODUCTS; ONE PROJECT → MANY ASSETS; ONE CONNECTOR → MANY WORKFLOWS; ONE RESULT → MANY LEARNINGS; ONE CUSTOMER RESULT → MANY OPPORTUNITIES.
## Permanent rule
Choose the highest-leverage coherent scope that can safely be built, tested, falsified, measured and verified together.
## Boundaries
Compounding never creates authority. No self-merge, self-spend, autonomous contract, signing, deletion or production authority.
