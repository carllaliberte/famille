# ACORN quantum interop readiness

Acorn treats future quantum-native and quantum-assisted intelligence as a **new capability entering the existing flow**, not as a second architecture.

The contract is deliberately provider-neutral. It supports future QPU, quantum-network, photonic, neutral-atom, trapped-ion, superconducting, spin-qubit, annealing and hybrid resources without making any provider the canonical one.

The important distinction is preserved:

- quantum hardware is compute, not authority;
- a QPU is not automatically an intelligence;
- a simulator is not a QPU;
- a quantum-capable intelligence is not trusted merely because it exists;
- quantum advantage is never asserted without comparative evidence;
- paid execution remains human-authorized;
- classical fallback remains available unless a task explicitly requires QPU execution.

The adapter is designed to plug into the existing Cortex → capability routing → compute fabric → evidence/measurement flow.
