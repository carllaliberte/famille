# ACORN — UNIVERSAL AI FEDERATION FABRIC

Acorn now treats external AI, tools, data, compute and partner organizations as interchangeable participants in a capability federation.

## Core model
PARTICIPANT → CAPABILITY → EVIDENCE → QUALIFICATION → FEDERATION GRAPH → COMPOSITION → COMMERCIAL BUNDLE → AUTHORIZATION → EXECUTION → MEASUREMENT → REBALANCING.

The participant identity is deliberately separated from the capability it contributes. A provider can disappear while the capability remains discoverable elsewhere.

## Economic optimization
Federated commercial bundles can combine several enterprises and capabilities. The system can compare expected capability value against cost, then use measured value and measured cost to propose future optimization. A proposal never becomes an executed contract automatically.

## Continuous operation
Discovery, qualification, graph rebuilding and measurement are designed to run continuously. Expired evidence downgrades trust rather than being silently reused.

## Governance
Automatic signature, spending, authority transfer and merge are forbidden. Breaker is immutable and untouched.

## Strategic result
Acorn becomes a neutral coordination and value layer above models, protocols and vendors: the network can expand without requiring Acorn to hard-code every future AI.
