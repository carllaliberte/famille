# ACORN — DEBUG ALL CONVERGENCE
Every open PR is treated as work to audit, not as an alternative main.

MAIN is reality. Diverged branches are recovered into clean branches when useful; they are not allowed to silently redefine architecture.

## Continuous debug
DISCOVER → CLASSIFY → RECOVER → TEST → FALSIFY → MEASURE → VERIFY → RECHECK.

## Required truth
A PR being open, mergeable, green locally, or documented does not prove LIVE execution. External activation remains explicitly observed/measured.

## Governance
No automatic merge. No authority escalation. Breaker is never touched.
