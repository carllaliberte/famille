# ACORN — UNIVERSAL WORLD INFRASTRUCTURE OS

This is the convergence fabric for the whole Acorn system. It does not replace existing fabrics; it composes them through one provider-neutral world model.

## Coverage
WORLD, CUSTOMER, MARKET, PRODUCT, PROJECT, CAPABILITY, INTELLIGENCE, CONNECTIVITY, DATA, COMPUTE, SOFTWARE, PHYSICAL, ROBOTICS, INDUSTRIAL, ENERGY, SECURITY, IDENTITY, ECONOMICS, EVIDENCE, QUALITY, OPERATIONS, EVOLUTION, FEDERATION.

## End-to-end loop
OBSERVE WORLD → DISCOVER DEMAND → DISCOVER CAPABILITY → QUALIFY → COMPARE → COMPOSE → SIMULATE → PROVISION → CONNECT → AUTHORIZE → EXECUTE → OBSERVE RESULT → VERIFY → DELIVER → MEASURE VALUE → BENCHMARK → LEARN → REGISTER → PRODUCTIZE → SCALE → RECOMPOSE → RECOVER → REOBSERVE.

## Meaning

The environment fabric becomes one part of a larger world fabric: environments host capabilities; capabilities compose into projects; projects produce outcomes; verified outcomes become reusable capabilities; capabilities create products and opportunities; opportunities feed back into the world.

## Boundaries

No capability becomes authority. No simulation becomes execution. No payment becomes execution proof. No execution becomes customer value without measurement. No code presence becomes LIVE.

Consequential effects remain explicitly authorized by the appropriate human/server control.

## Optimization

The system optimizes measured outcomes within an explicit scope and validity horizon. “Best” means BEST_KNOWN_IN_SCOPE, never an unsupported global optimum.

## Future compatibility

New providers, environments, machines, markets, intelligence types and physical systems enter through generic contracts rather than a fixed allowlist. Unknown remains measurable research work, not invented capability.
