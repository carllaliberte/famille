# ACORN — World Engine Architecture

The World Engine is a convergence layer, not a new independent runtime.

### Five planes

1. **Intent plane** — customer and human objective.
2. **Capability plane** — discovery, adapters, providers and reusable assets.
3. **Execution plane** — existing operational/runtime/connector fabrics.
4. **Evidence plane** — existing evidence, quality and provenance fabrics.
5. **Value plane** — existing commercial, economic and outcome fabrics.

### Universal graph

ACTOR → NEED → CAPABILITY → RESOURCE → TASK → PROJECT → OFFER → ORDER → PAYMENT → AUTHORIZATION → EXECUTION → EVIDENCE → MEASUREMENT → OUTCOME → VALUE → REUSE.

Time, rights, provenance and authority cross-cut every edge.

### Failure path

FAIL → DIAGNOSE → RETRY → SUBSTITUTE → RECOMPOSE → ESCALATE_HUMAN.

### Expansion

One project can create reusable knowledge and capabilities. Those capabilities can become products and serve new markets. New outcomes feed the benchmark and return to the observation loop.
