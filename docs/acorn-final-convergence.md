# ACORN — FINAL CONVERGENCE CHARTER

Acorn is organized as a universal intent-to-reality system.

The unit of computation is not an application. It is an **intent**, compiled into needs, capabilities, resources, actors, tasks, rights, constraints and measurable outcomes.

The system therefore supports the same fabric for software, research, enterprise operations, creative work, engineering, automation, physical systems and future capability classes without giving any provider or intelligence special authority.

## Permanent adaptation

WORLD → OBSERVE → GAP → DISCOVER → COMPARE → COMPOSE → SIMULATE → QUALIFY → EXECUTE → MEASURE → FALSIFY → VERIFY → REGISTER → REUSE → RECOMPOSE → WORLD.

Unknown remains unknown until measured. Expired evidence returns to observation. Failed execution becomes a diagnostic/recomposition opportunity. Successful verified outcomes become reusable capability candidates.

## Commercial compounding

DEMAND ↔ CAPABILITY → PROJECT → OFFER → ORDER → PAYMENT_OBSERVED → AUTHORIZATION → EXECUTION → VALUE → REUSE.

The system may measure and optimize economic value, but it cannot silently spend money, sign contracts, alter protected prices, publish, delete or merge.

## Human sovereignty

CAPABILITY ≠ AUTHORITY.

The system can become broader, faster, more adaptive and more capable without becoming the authority that governs itself.

## Operating principle

Transform human intention into measurable reality, then transform measured reality into new capability — continuously, with evidence, expiry, provenance and human sovereignty.
