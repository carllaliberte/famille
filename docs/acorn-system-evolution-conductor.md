# Acorn System Evolution Conductor
Contract: `acorn.system-evolution-conductor.v1`

The conductor is the higher-order continuous measurement loop. It composes existing context, interoperability and measured convergence fabrics; it does not create a second Cortex, memory, capability mesh, execution runtime or authority system.

Cycle:
INGEST → CONTEXTUALIZE → MEASURE → RECONCILE → DETECT_GAPS → GENERATE_CANDIDATES → SIMULATE → REQUEST_HUMAN_AUTHORIZATION → ADOPT_THROUGH_GOVERNANCE → OBSERVE → VERIFY → LEARN → REOBSERVE.

Every candidate is evidence-bound and requires human authorization before consequential adoption. The conductor reports gaps rather than inventing completion.

Truth boundaries:
- context is time-bounded, not truth;
- structural interoperability is not live connectivity;
- measured convergence is not completion;
- learning is not authority;
- capability is not authority.
