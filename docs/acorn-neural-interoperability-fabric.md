# ACORN NEURAL INTEROPERABILITY FABRIC
Contract: acorn.neural-interoperability-fabric.v1

This is the connective tissue between Acorn organs. It does not create a second Cortex, execution runtime, Governor, Breaker, evidence registry or authority system.

NODE TYPES:
CORTEX · PERCEPTION · WORLD_MODEL · MEMORY · CAPABILITY · INTELLIGENCE · TOOL · RESOURCE · EVIDENCE · ACTION · OUTCOME · GOVERNANCE · PROJECT · CUSTOMER · CONNECTOR · EXPERIMENT

SIGNAL FLOW:
PERCEPTION → CONTEXT → MEMORY → DISCOVERY → CAPABILITY → PLAN → AUTHORIZATION → GOVERNED ACTION → OUTCOME → EVIDENCE → MEASUREMENT → LEARNING → REOBSERVATION

All consequential action remains delegated to existing governance. Structural interoperability is not proof of live connectivity. Learning never changes authority.

The objective is maximum interoperability with minimum duplicated architecture.
