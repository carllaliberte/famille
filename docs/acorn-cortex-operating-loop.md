# ACORN — CORTEX OPERATING LOOP
This fabric closes the operational cognition loop around the existing Acorn Cortex, World State, Project Compiler, Value Optimizer and Ecosystem Memory work.

## Continuous nervous-system model
WORLD CHANGE / DEMAND / OPPORTUNITY / RISK / CAPABILITY CHANGE / OUTCOME
→ RECEIVE
→ CONTEXTUALIZE with shared knowledge and capabilities
→ COMPOSE candidate responses
→ SCORE against value, cost and risk
→ PROPOSE the next best action
→ HUMAN/SERVER AUTHORIZATION where consequential
→ EXECUTE through existing authorized infrastructure
→ MEASURE outcome
→ LEARN
→ REUSE validated patterns.

## Why this matters
Acorn can continuously perceive changes and turn distributed knowledge into coordinated proposals without requiring a single AI model to be the "brain". Models, people, companies, tools and machines remain participants.

## Fluidity
The cortex does not require one protocol, provider or API. It consumes normalized signals from the existing capability/connector/bridge fabrics.

## Governance
Automatic authorization and consequential execution remain forbidden. Learning must remain traceable. Breaker remains untouched.
