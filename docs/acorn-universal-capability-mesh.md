# ACORN Universal Capability Mesh

Contract: `acorn.universal-capability-mesh.v1`.

The mesh makes **Capability** the portable unit between intelligences, tools, connectors and projects without turning any participant into an authority.

## Lifecycle
DECLARE → DISCOVER → NORMALIZE → QUALIFY → MEASURE → ROUTE → COMPOSE → EXECUTE THROUGH EXISTING GOVERNANCE → OBSERVE → VERIFY → LEARN → EXPIRE_OR_REVOKE → REDISCOVER.

## Guarantees
- Capability ≠ Authority.
- Qualification requires measured + verified evidence.
- Routing is scoped to qualified capabilities and context.
- Learning requires measured + verified outcomes.
- Expiration and revocation are explicit.
- No auto-authorization, auto-execution, auto-spend, Breaker bypass or hidden learning.
- External effects remain delegated to the existing Effect Governor / Execution Fabric / Breaker path.
- This is one mesh, not a second Cortex.

## Reality
A capability is not LIVE merely because it is declared, configured or routable. Physical reality remains established only by the existing connectivity/reality evidence chain.
