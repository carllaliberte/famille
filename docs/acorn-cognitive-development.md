# ACORN — COGNITIVE DEVELOPMENT LOOP

The development target is no longer only software capability. It is the measurable growth of collective cognition.

## Cognitive dimensions
Knowledge, memory, reasoning, context, discovery, composition, prediction, learning, transfer, collective coordination and human complementarity.

## Development loop
EXPERIENCE → CONTEXT → EVIDENCE → LESSON → VALIDATION → TRANSFER → NEW EXPERIENCE → MEASURE → PRIORITIZE → DEVELOP.

Every useful episode preserves context, observations, actions, outcome, feedback and evidence. Lessons remain provisional until validated.

## Cortex effect
The same validated lesson can become available to multiple compatible participants without forcing a single model, vendor or protocol to become the cognitive center.

## Optimization rule
Future work is prioritized by measured cognitive gaps and expected compounding value. The objective is to make the whole environment progressively better at understanding, remembering, reasoning, composing, predicting and learning.

## Safety
Collective cognition never becomes automatic authority. No hidden learning, automatic merge, spending, signature or Breaker access.
