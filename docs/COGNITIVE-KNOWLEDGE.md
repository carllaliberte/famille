# ACORN Cognitive Knowledge Exchange

The cognitive knowledge contract is the executable information-sharing path between connected intelligences and Acorn Cortex.

`intelligence → contribution → Cortex ledger → retrieval/discovery → composition → measurement → updated contribution`

A contribution is provenance-aware, temporally bounded when applicable, append-only, deterministic and idempotent. A contribution never becomes truth merely because it was ingested. `declared`, `observed`, `measured`, `verified` and `retracted` remain explicit states.

Only externally shareable material is accepted. Private chain-of-thought, credentials, secrets and provider-internal confidential material are excluded.

Existing roster identities can be backfilled through the same ingestion path. Backfill establishes declared knowledge only; it does not establish connection, execution, measurement or LIVE status.

The ledger is a logical append-only history. Supersession and retraction are represented by new records rather than mutation of historical records.

This contract belongs inside the existing Cognitive Contracts / Cognitive Fabric / Synaptic Discovery / Evidence / Measurement / Provenance architecture. It is not a new architecture layer.
