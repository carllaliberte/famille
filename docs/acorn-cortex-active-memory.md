# ACORN — ACTIVE CORTEX MEMORY
The Cortex is no longer only a knowledge registry. It continuously correlates environmental signals with traceable memory, prioritizes relevant signals, retrieves context, generates provisional predictions and closes the loop with measured outcomes.

## Continuous cycle
RECEIVE → CORRELATE → PRIORITIZE → RETRIEVE → PREDICT → PROPOSE → EXECUTE WHEN AUTHORIZED → OBSERVE → MEASURE ERROR → LEARN → UPDATE MEMORY.

## Environmental cognition
The same fabric can represent signals from humans, organizations, software, AI systems, tools, physical systems and markets. The Cortex does not require one provider or one protocol.

## Knowledge quality
Memory carries provenance, confidence, scope and expiry. Predictions are provisional. Learning is driven by observed outcomes, not by self-declared success.

## Governance
The Cortex coordinates information; it does not acquire authority. Automatic consequential action, hidden memory, authority transfer, spending, signing, merging and Breaker access remain forbidden.
