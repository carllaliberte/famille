# ACORN — MAXIMAL DEVELOPMENT CONVERGENCE

This contract makes the user's grand-chantiers principle executable.

## Objective

Maximize the largest coherent unit of development that can be safely built, tested, falsified, measured and verified together.

This is not permission to create arbitrary monoliths. Scope is expanded only when work shares primitives, dependencies, outcomes, architecture or value.

## Permanent pipeline

OBSERVE MAIN → AUDIT ALL OPEN WORK → DISCOVER GAPS → GROUP BY COHERENCE → DEPENDENCY ANALYSIS → COMPOSE GRAND SCOPE → DESIGN SHARED PRIMITIVES → BUILD → TEST → FALSIFY → MEASURE → VERIFY → RECHECK MAIN → DELIVER → REOBSERVE → RECOMPOSE.

## Optimization vector

COHERENCE · INTEGRATION · REUSE · CUSTOMER VALUE · QUALITY · RELIABILITY · SPEED · COST · SECURITY · EVIDENCE · MAINTAINABILITY · FUTURE COMPATIBILITY.

Maximize the first five and minimize duplication and fragmentation, subject to truth, safety and human authority.

## Important

A larger chantier is preferred only when it is more coherent. Artificial bundling is fragmentation in disguise.

No auto-merge. No auto-spend. No autonomous contracts. No authority escalation.
