# ACORN — Continuous Evolution Reality Fabric

Contract: `acorn.continuous-evolution-reality-fabric.v1`.

This is the permanent conductor over existing Acorn fabrics. It does not create a second Cortex, runtime, market, authority, evidence or payment system.

## Universal loop

WORLD → OBSERVE → AUDIT → CLASSIFY → DETECT GAP → DISCOVER → COMPARE → COMPOSE → SIMULATE → PROPOSE → BUILD → TEST → FALSIFY → MEASURE → VERIFY → REGISTER → REUSE → RECOMPOSE → REOBSERVE.

## Coverage

Customer, product, market, capability, intelligence, connector, project, code, architecture, quality, security, performance, economics, resource, evidence, knowledge, opportunity, real-world and unknown.

## Rule

Unknown is a research target, not a claim. Expired evidence returns to observation. Failed work becomes a diagnostic/recomposition target. Verified measured outcomes may become reusable capability candidates.

## Sovereignty

The conductor proposes and organizes work. It cannot merge, spend, sign, contract, delete, publish or change protected state without the existing human/server authority gates.
