# ACORN UNIVERSAL SEMANTIC EVENT SPINE
Contract: acorn.universal-semantic-event-spine.v1

A shared semantic event/history spine for the entire organism.

It provides:
- canonical event envelopes;
- provenance, causation and correlation identifiers;
- idempotent append;
- replay and temporal filtering;
- lineage and unresolved-causation detection;
- bridges from the neural fabric into durable semantic history.

This is not a second memory, execution runtime or authority system. It is the connective event/history protocol used by existing organs.

Architecture:
ORGAN → SEMANTIC EVENT → SPINE → LINEAGE / REPLAY → EXISTING MEMORY + EVIDENCE + OBSERVABILITY + LEARNING

An event is evidence of an emitted event, not proof that the described real-world state is true.
