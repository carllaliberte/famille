# ACORN — UNIVERSAL NETWORK CONVERGENCE
## Purpose
The original connector registry remains the ingress membrane. Every connector/provider/tool/intelligence can exchange capability envelopes through a common, traceable transport fabric.

## Flow
CONNECTOR REGISTRY → CAPABILITY ENVELOPE → DISCOVERY → ROUTING → NEGOTIATION → FLOW PLAN → EXECUTION → OBSERVATION → MEASUREMENT → REUSE.

## Fluidity
Routes are selected from measured/scoped latency, reliability, hop count, friction and cost. Flow plans carry bounded concurrency, timeout and retry budgets plus explicit backpressure. A failed hop is STALLED/RETRYABLE, never silently skipped.

## Coverage
The fabric is provider-neutral and intended to cover AI, cloud, compute, data, code, communications, productivity, design, commerce, research, observability, security, IoT, robotics, industrial, energy and future connectors.

## Safety
Capability is not authority. A connector transports/executes only within its existing authorization contracts. The network fabric does not create money, contract, signing, deletion, publication, merge or production authority.

## Breaker
**BREAKER IS EXPLICITLY OUT OF SCOPE AND MUST NOT BE MODIFIED.** The convergence layer observes its boundary only; it never edits, bypasses or replaces it.

## Truth
CODE_PRESENT ≠ TESTED ≠ EXECUTED ≠ MEASURED ≠ VERIFIED ≠ LIVE.
