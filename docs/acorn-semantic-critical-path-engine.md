# ACORN SEMANTIC CRITICAL PATH ENGINE
Contract: acorn.semantic-critical-path-engine.v1

Replaces degree-based “critical path” approximations with measured graph reachability, dependency depth, roots, leaves and bounded blast radius.

The engine distinguishes structural dependency from causality: graph reachability is not proof of real-world impact, and structural depth is not causal importance.

Cycle:
INVENTORY → RESOLVE EDGES → MEASURE DEPTH → MAP REACHABILITY → CHECK EVIDENCE → PRIORITIZE OBSERVATION → REOBSERVE

No authority, auto-execution or LIVE claims.
