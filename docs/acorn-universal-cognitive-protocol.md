# ACORN Universal Cognitive Protocol

Contract: `acorn.universal-cognitive-protocol.v1`

This is the interoperability contract joining existing Acorn fabrics through a common envelope, schema/version negotiation, adapter routing and validation.

It does **not** create a second Cortex, memory, execution runtime, authority system or event store.

## Purpose

A future intelligence, connector, tool or compute backend should be able to participate by implementing the protocol rather than being hard-coded into a provider allowlist.

## Rules

CAPABILITY != AUTHORITY  
DEFINED != EXECUTED  
CONNECTED != LIVE  
OBSERVED != VERIFIED

Negotiation proves compatibility only. Routing proves protocol compatibility only. Neither grants authority or proves real-world execution.

Consequential actions remain under the existing governance and human authorization path.
