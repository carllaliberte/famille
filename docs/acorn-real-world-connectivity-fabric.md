# ACORN Real-World Connectivity Fabric

Contract: `acorn.real-world-connectivity-fabric.v1`

This is the bridge from the ACORN Nervous System to real environmental connections. It does not create a second nervous system, router, execution runtime, authority system, or economy.

## Reality ladder

DECLARED → CONFIGURED → PROBE_SENT → CONNECTED → LIVE_VERIFIED

A connector is never considered live because a URL, credential reference, adapter, or configuration exists.

For LIVE_VERIFIED, ACORN requires physical observation plus authentication/usability evidence and dated evidence records.

## Integration

WORLD → CONNECTIVITY FABRIC → NERVOUS SYSTEM → CORTEX/BRAIN → EXISTING EFFECT GOVERNOR → EXISTING EXECUTION FABRIC → OBSERVATION

Outbound consequential effects remain blocked until the existing human authorization, effect-governor and Breaker boundaries are satisfied.

## First-class connector categories

Intelligence, data, communication, productivity, commerce, developer, infrastructure and observability.

The architecture is provider-neutral: new intelligences and services can enter through capability contracts without creating a fixed provider allowlist.

## Truth boundary

DEFINED ≠ EXECUTED ≠ MEASURED ≠ LIVE VERIFIED.

No LIVE claim is created by this module alone.
