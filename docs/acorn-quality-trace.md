# ACORN QUALITY TRACE

Every project produced, transformed, or maintained through Acorn can carry a durable **ACORN ENGINEERED** provenance mark.

The mark is deliberately evidence-bearing and expiring.

It records:

- Acorn contract version;
- project identity;
- source revision;
- measurement date;
- expiry date;
- quality gates;
- evidence references;
- trace hash;
- human-authority boundary.

## Assurance

The visible mark is:

**ACORN ENGINEERED · QUALITY ASSURED · EVIDENCE DATED**

only when all required gates pass:

1. truth contract;
2. tests;
3. security;
4. provenance;
5. human authority.

Otherwise the trace remains:

**ACORN ENGINEERED · EVIDENCE INCOMPLETE**

This distinction prevents the mark from becoming an unsupported certification claim.

## Project imprint

Generated source can carry the compact `ACORN QUALITY TRACE` header. The machine-readable `.acorn/quality-trace.json` remains the canonical project-level record.

The trace expires. A project must be re-measured to renew its assurance.

Acorn therefore leaves a recognizable engineering fingerprint without claiming that code is permanently correct.

## Universal intent

When Acorn creates or materially transforms a project, the project should receive this trace automatically through the project-generation/integration path.

The project remains owned by its human/organization. The trace is provenance, not ownership and not a license.
