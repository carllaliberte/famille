# ACORN — TOTAL CORTEX CONVERGENCE

This is the integration point for the ecosystem-wide cortex.

## What the cortex does
Acorn continuously normalizes signals from knowledge, capabilities, intelligences, connectors, partners, projects, resources, execution, evidence, measurement, value, learning and the surrounding environment.

It does not replace those actors. It makes their state discoverable, comparable and composable.

## Fluidity
A single normalized signal can be routed across the system without forcing every participant onto the same model, vendor, API or protocol.

## Project intelligence
Human intent can be transformed into a project plan while the cortex identifies capability/resource gaps. Missing capability becomes a discovery problem, not a dead end.

## Collective knowledge
Measured outcomes feed learning priorities. High-value demonstrated patterns become candidates for reuse and recomposition.

## Continuous loop
OBSERVE → QUALIFY → COMPOSE → PROPOSE → AUTHORIZE → EXECUTE → VERIFY → MEASURE → LEARN → RECOMPOSE.

## The key property
Acorn can know what appears beneficial **because it can compare observed outcomes against explicit objectives and evidence**. It does not declare something good merely because the system produced it.

## Governance
The cortex has no autonomous authority. It cannot merge, spend, sign, transfer authority or touch Breaker. Learning remains traceable and stale knowledge/signals expire explicitly.
