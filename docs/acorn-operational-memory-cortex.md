# ACORN — OPERATIONAL MEMORY CORTEX
Acorn records what happened, what was observed, what resulted, what it cost and what evidence supports it.

Flow:
EPISODE → EVIDENCE → LESSON → VALIDATION → CONSOLIDATION → RECALL → NEW ACTION → OUTCOME.

Memory is operational, not merely archival. Relevant validated lessons can be recalled when a future goal resembles a prior episode. Expiry is explicit.

The memory cortex does not silently learn or acquire authority. Every lesson retains provenance and validation state. Human governance remains outside the memory mechanism.

This connects the knowledge cortex to the self-optimization engine: measured outcomes become reusable knowledge, and reusable knowledge informs future composition and routing.
