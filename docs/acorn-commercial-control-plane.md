# ACORN — Commercial Control Plane

**DISCOVERY → QUALIFY → SOLUTION → OFFER → HUMAN AUTHORIZATION → EXECUTE → VERIFY → DELIVER → ACCEPT → VALUE → ASSET → PRODUCT → EXPANSION**

This is the commercial integration layer around Acorn's existing customer, execution, evidence, delivery, value, asset and product fabrics.

### What it adds
- structured lead and qualification state;
- capability-driven solution design;
- priced offers and explicit usage rights;
- human authorization before consequential work;
- execution/result records and evidence;
- delivery + acceptance gates;
- measured revenue, customer value and margin;
- reusable asset capture;
- repeatable productization;
- expansion recommendations;
- command-center metrics for funnel, execution, economics and reuse.

### Commercial flywheel
**One difficult problem → one complete delivery → one proof → one reusable asset → one product → repeated demand.**

Projected value stays projected. Payment is not a receipt. External settlement requires evidence. Missing credentials or external evidence remains blocked/not configured rather than LIVE.

### Boundary
The plane does not autonomously sign contracts, capture/transfer money, spend, hold keys, publish, outreach, or merge code.

### North star
**Problem → Complete solution → Proof → Delivery → Value → Asset → Product → Repeat.**
