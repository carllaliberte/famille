# ACORN — Universal Opportunity Intelligence

Acorn continuously searches for useful **capabilities, resources, free tiers, credits, open-source components, APIs, MCP surfaces, compute, data, grants, startup programs, market needs and reusable project patterns**.

Core loop:

WORLD → DISCOVER → QUALIFY → COMPARE → COMPOSE → EXECUTE → MEASURE → REUSE

Discovery never becomes authority. External pricing, quotas, eligibility and availability require fresh evidence before being treated as current.

## Compounding

A measured project outcome can produce a reusable project template/capability candidate. That candidate can later be qualified again for another customer or problem.

## Developer Hall

Developer contributions can be attributed and showcased using evidence without claiming endorsement, partnership, sponsorship, usage or revenue unless independently evidenced.

## Economic principle

Prefer sufficient free/open/credit resources before paid resources, subject to capability, quality, limits, rights, privacy and customer constraints.

FREE ≠ UNLIMITED.
DISCOVERED ≠ VERIFIED.
ATTRIBUTION ≠ ENDORSEMENT.
