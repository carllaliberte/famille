# ACORN — Universal Capability Router

The connection mesh exposes possibilities. The router turns them into measured choices.

For every task, Acorn can compare compatible routes using:
capability fit, quality, latency, reliability, cost, freshness, evidence, privacy and availability.

The selection is explicitly **BEST_KNOWN_IN_SCOPE**, never an unsupported claim of global optimum.

Execution results feed back into the route record so future choices improve.

CAPABILITY ≠ AUTHORITY.
Ranking ≠ authorization.
Measured route ≠ guaranteed result.
