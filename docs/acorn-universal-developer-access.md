# ACORN — Universal Developer Access Fabric

## Purpose

One provider-neutral fabric for developer ecosystems, present and future.

`DISCOVER → CLASSIFY ACCESS → AUTHENTICATE → DISCOVER CAPABILITIES → ROUTE → EXECUTE → MEASURE → VERIFY → REUSE`

The catalog is a **discovery seed**, not proof of live access. A seeded provider is never reported as connected, authenticated, paid, verified or live.

## Coverage

The initial discovery vocabulary spans OpenAI, Anthropic, Google, xAI, Mistral, Cohere, DeepSeek, Groq, Cerebras, NVIDIA, Meta, AWS, Microsoft, Cloudflare, GitHub, Hugging Face, OpenRouter, Together, SambaNova, Perplexity, Vercel, Supabase, MongoDB, PostgreSQL, Docker, Kubernetes, Stripe, Twilio, Slack, Discord, Linear and Figma.

This is intentionally extensible. Unknown providers and capabilities become `DISCOVERED` future surfaces instead of requiring an architecture rewrite.

## Free-first optimization

Acorn can rank:

1. permanent free / open-source / self-hosted
2. free trials / credits / startup / community access
3. unknown / unmeasured
4. paid

within the actual capability and budget constraints.

**FREE ≠ UNLIMITED.** Quotas, terms, region, model availability and account status must be measured before claiming usable access.

## Security

- API keys are environment references only.
- No secrets are stored in catalog entries.
- `CAPABILITY ≠ AUTHORITY`.
- Discovery cannot authorize consequential actions.
- `DISCOVERED ≠ CONNECTED ≠ EXECUTED ≠ VERIFIED ≠ LIVE`.
- No automatic spend, contract, merge or publication.

## Future-proofing

A new ecosystem can be registered through `registerFutureDeveloperSurface()`. The same contract can represent a future API, SDK, MCP server, tool protocol, model, compute service or developer platform without a fixed provider allowlist.

## Evidence

External facts about pricing, free quotas, credits and eligibility must be refreshed from authoritative provider documentation before being treated as current. This repository stores capability hypotheses and runtime observations separately.

## Economic loop

`NEED → CAPABILITY DISCOVERY → FREE/CREDIT/PAID ROUTING → EXECUTION → MEASUREMENT → BEST-KNOWN RESULT → REUSE`

No claim of free access is made merely because a provider appears in the seed catalog.
