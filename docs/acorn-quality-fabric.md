# ACORN QUALITY FABRIC

The Quality Fabric is a cross-cutting contract over the existing Acorn runtime. It is not a second runtime, project engine, evidence engine, market engine or authority engine.

## The idea pushed to the maximum

Quality becomes a universal temporal property of every material object Acorn touches: problem, architecture, capability, provider, connector, code, dependency, project, execution, deliverable, customer outcome and reusable asset.

Core truth:

CODE_PRESENT != TESTED != EXECUTED != MEASURED != VERIFIED != LIVE

## Quality passport

A passport carries identity, version, revision, provenance, dependency lineage, 26 dimensions, evidence, measurements, limitations, rights, customer validation, economic measurements, authority boundaries and expiry.

It is evidence, not ownership, authority or permanent certification.

## Quality composition

QUALITY(A) + QUALITY(B) + COMPATIBILITY + PROVENANCE + CURRENT_EVIDENCE -> QUALITY(C)

A composed capability does not silently inherit the quality of its parts.

## Adversarial quality

CLAIM -> FALSIFICATION -> ATTACK -> FAILURE -> PATCH -> TEST -> RETEST -> VERIFY

Builder and verifier are separated where practical. Failures remain evidence.

## Customer outcome

OBJECTIVE -> OBSERVATION -> MEASUREMENT -> CUSTOMER_VALIDATION

Execution success is not automatically customer success.

## Provider quality

Providers are evaluated from observed samples: success, failure, latency, cost, capability match and evidence freshness. Provider identity is not a quality shortcut.

## Temporal quality

CURRENT -> MONITOR -> DRIFT -> REMEASURE -> REVERIFY

Expired evidence expires the proof, not reality itself.

## Self-repair

DETECT -> DIAGNOSE -> SELECT_ALTERNATIVE -> SIMULATE -> TEST -> FALSIFY -> MEASURE -> VERIFY -> HUMAN_AUTHORIZE

Repair can be prepared and proposed; critical authority remains human.

## Economic quality

ESTIMATE != ACTUAL != VALUE != REVENUE

Payment is a commercial observation, not execution proof.

## Compounding

A verified capability may be reused only when provenance, rights, compatibility and current evidence remain valid. Material composition requires new evidence.

## Universal lifecycle

INTAKE -> ARCHITECT -> COMPOSE -> BUILD -> TEST -> FALSIFY -> MEASURE -> VERIFY -> TRACE -> OFFER -> ORDER -> AUTHORIZE -> EXECUTE -> OBSERVE -> VALIDATE -> DELIVER -> MEASURE_VALUE -> MONITOR -> DETECT_DRIFT -> REMEASURE -> REVERIFY -> REUSE -> RECOMPOSE -> LEARN

## Human sovereignty

authority = human
auto_merge = false
quality does not grant authority

customer value requires measurement
payment does not prove execution
self-repair does not self-authorize
