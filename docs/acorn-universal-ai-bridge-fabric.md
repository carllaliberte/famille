# ACORN — UNIVERSAL AI BRIDGE FABRIC

AI models are participants in a capability fabric, not hard-coded organs.

Bridge modes: NATIVE, OPENAI_COMPATIBLE, HTTP, SDK, LOCAL, MCP, CLI, WEB and FUTURE_ADAPTER.

A new model can be discovered and represented through a generic bridge without redesigning Acorn. Selection is capability-first. If one bridge fails, the capability remains routable through another bridge or a native substrate.

API availability is never a prerequisite for cognition. Credentials are never stored in the repository. External effects remain governed. Automatic discovery and adapter construction do not grant authority.

Flow: DISCOVER CAPABILITY → DISCOVER MODEL → DESCRIBE BRIDGE → QUALIFY → MEASURE → SELECT → ADAPT → EXECUTE → OBSERVE → VERIFY → REUSE.

Breaker is immutable and untouched.
