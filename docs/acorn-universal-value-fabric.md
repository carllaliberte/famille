# ACORN UNIVERSAL VALUE FABRIC

A common typed temporal graph for demand, capability, project, commerce, execution, evidence, outcome, value and reuse.

It composes the existing Market Engine, Infinite Economic Engine, Project Runtime and Quality Fabric; it does not replace them.

WORLD → DEMAND ↔ CAPABILITY → COMPOSITION → PROJECT → OFFER → ORDER → PAYMENT_OBSERVED → AUTHORIZATION → EXECUTION → EVIDENCE → OUTCOME → VALUE → REUSE → NEW_DEMAND

Human intent compiles into NEED → TASKS → CAPABILITIES → COMPOSITION → PROJECT.

Commercial truth remains explicit: OFFER ≠ ORDER ≠ PAYMENT_OBSERVED ≠ AUTHORIZATION ≠ EXECUTION ≠ VALUE.

A delivered project can become reusable capability only with current evidence, provenance, rights and compatibility.

Human authority remains human; no self-merge, self-sign, self-spend, self-publish or invented reality.
