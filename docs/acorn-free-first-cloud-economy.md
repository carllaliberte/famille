# ACORN — FREE-FIRST CLOUD ECONOMY

## Policy

**FREE_PERMANENT → FREE_QUOTA → SPONSORED → TRIAL → PAID → UNKNOWN**

A provider's marketing claim is not evidence by itself. Acorn retains provenance, verifies the offer, and measures actual limits and availability before promoting a resource.

## Current baseline

Oracle documents Always Free resources as available for the life of an OCI account, with limits. GitHub documents standard GitHub-hosted runners as free for public repositories. These external facts must be periodically revalidated and are not hard-coded guarantees.

## Architecture

GitHub/main remains source of truth. The persistent cloud substrate executes the existing canonical:

**CORTEX → CONTINUOUS RUNTIME → WORK ENGINE**

The cloud runner is only an execution substrate. It is not a second Cortex, second authority, or competing runtime.

Persistent state is stored on a mounted /data volume or equivalent durable cloud storage. It remains evidence-backed and versioned by the canonical work engine.

## Economics

No paid resource is selected merely because it is faster.

A paid resource requires:
1. verified resource identity;
2. measured capability;
3. measured cost;
4. sufficient measured revenue or explicit human authorization;
5. Resource Governor approval.

No automatic spending, contracting, or merging is introduced.

## Failover

Multiple substrates for the same capability are allowed. Acorn ranks them by free class, verification, availability and measured performance. If a selected substrate becomes unavailable, a compatible verified alternative can be selected.

## Deployment reality

This change prepares the persistent cloud substrate and its contracts. It does **not** claim that a cloud account has already been provisioned. Actual provisioning requires an account and credentials and remains human-authorized where cost can occur.

## Target loop

**DISCOVER → CLASSIFY → VERIFY → MEASURE → ALLOCATE → EXECUTE → OBSERVE → FAILOVER → LEARN**

**CAPABILITY ≠ AUTHORITY**

**Evidence > assertion**

**Measurement > assumption**

**Verification before trust**
