# ACORN — CORTEX SIGNAL & CONTEXT ROUTER

The cortex becomes an operational signal layer between the environment and collective cognition.

## Flow
WORLD → SIGNAL → CLASSIFY → ROUTE → CONTEXT → REASON → PROPOSE → AUTHORIZE → EXECUTE → MEASURE → LEARN.

Signals include needs, changes, risks, opportunities, failures, outcomes, knowledge and capabilities.

The router connects each signal to relevant participants, capabilities and verified/provisional knowledge. Context is bounded to prevent uncontrolled accumulation.

The system ranks possible next actions by expected value, cost and risk, but produces a proposal requiring authorization. It never silently acts because it found an apparently optimal action.

## Continuous cognition
Measured outcomes become inputs for future routing and optimization. Expiry is explicit. Traceability is mandatory.

## Constitution
CAPABILITY ≠ AUTHORITY.
REASONING ≠ EXECUTION.
PROPOSAL ≠ AUTHORIZATION.
No hidden context, automatic consequential action, authority transfer or Breaker access.
