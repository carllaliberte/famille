# ACORN — Universal Connection Mesh

The mesh is Acorn's open-ended connection registry.

It deliberately separates:
DISCOVERED → CONFIGURED → AUTHENTICATED → CONNECTED → READABLE → EXECUTABLE → MEASURED → VERIFIED

A provider list is only a discovery seed. It is not evidence of an active account, API key, connection or partnership.

The mesh covers AI, cloud, code, data, communications, productivity, design, commerce, research, observability, security, IoT, robotics, industrial systems, energy and future providers.

MCP and HTTPS are preferred interoperability paths where supported; other protocols may be registered dynamically.

The registry is designed to accept new providers and surfaces without changing the core architecture.

CAPABILITY ≠ AUTHORITY.
READ/PROPOSE can be discoverable; WRITE/MONEY/PUBLISH/SIGN/DELETE/MERGE require explicit human authorization.
No secrets are stored by this contract.
