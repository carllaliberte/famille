# ACORN — Intent → Reality Compiler

The compiler is the unifying orchestration contract over existing Acorn fabrics. It does not create a second runtime.

## Permanent loop

`HUMAN INTENT → QUALIFICATION → CAPABILITY DISCOVERY → COMPOSITION → COMMERCIAL PATH → AUTHORIZATION → EXECUTION → EVIDENCE → MEASUREMENT → DELIVERY → CAPABILITY → ADAPTATION → DISCOVER AGAIN`

It reuses the Universal Value Fabric, Quality Fabric and Best-Known Result fabric.

## Truth

- a gap is explicit; no capability is invented;
- composition requires evidence;
- payment is not execution;
- execution is not value;
- measurement is required before capability reuse;
- adaptation is a proposal, not authority;
- consequential actions remain human-gated;
- no automatic merge.

The goal is a single customer-facing semantic compiler: transform a human problem into a measurable project graph, then transform measured reality into reusable capability and a new opportunity.
