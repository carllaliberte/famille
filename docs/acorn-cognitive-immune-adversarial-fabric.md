# ACORN Cognitive Immune & Adversarial Fabric
Contract: `acorn.cognitive-immune-adversarial-fabric.v1`

## Purpose
Provide the organism with a measurable immune layer: detect contradictions, anomalies, unverified inputs, injection-like signals, replay, drift and resource abuse; contain unsafe cognitive paths; learn only from verified outcomes.

Cycle:
**OBSERVE → DETECT → CLASSIFY → ASSESS TRUST → CONTAIN → ROUTE AROUND → OBSERVE → MEASURE → VERIFY → LEARN → HARDEN**

This is not a second authority system or execution engine. It protects cognition by making uncertainty and hostile/untrusted signals explicit.

## Integration
- World Model supplies observations and entities.
- Synaptic Fabric supplies cognitive paths.
- Cortex uses admissibility/containment results.
- Outcome Learning supplies verified learning outcomes.
- Effect Governor and Execution Fabric remain the only consequential-effect boundary.

## Boundaries
**CAPABILITY ≠ AUTHORITY**
**SUSPICION ≠ PROOF**
**BLOCKING ≠ EXECUTION**
**LEARNING requires measured + verified evidence**
**DEFINED ≠ EXECUTED ≠ MEASURED ≠ LIVE VERIFIED**

Containment may block a path. It never authorizes, spends, signs, merges, publishes or executes.

## Evolution
Future measured signals may add provider-specific anomaly detection, replay fingerprints, semantic contradiction detection, drift models, privacy/security indicators and adversarial benchmarks. Every new detector must be observable and falsifiable; unknown remains explicit.

## Definition of done
Contract + runtime + integration boundaries + evidence/provenance + tests + CI + documentation + evolution hooks in one durable branch.
