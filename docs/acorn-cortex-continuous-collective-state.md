# ACORN — CONTINUOUS COLLECTIVE CORTEX

This fabric turns distributed signals into a continuously updated, traceable environmental state.

## Cortex loop
SENSE → INGEST → CORROBORATE → DETECT CONFLICT → CONSOLIDATE → ROUTE → DERIVE → PROPOSE → AUTHORIZE → ACT → OBSERVE AGAIN.

The cortex does not assume consensus. Independent matching observations are corroborated; contradictory observations remain explicitly conflicted.

## Knowledge fluidity
Signals expire. Current state is rebuilt from live observations. Confidence and provenance travel with the signal so downstream intelligences can distinguish evidence from inference.

## Collective cognition
Actors can contribute observations and capabilities without surrendering their autonomy. Acorn makes relevant information discoverable across the ecosystem and lets specialized intelligences work from a common measured state.

## Optimization
The collective state feeds self-optimization, capability routing, project composition and commercial decisions. Every improvement is tested against observed outcomes.

## Governance
The cortex cannot transfer authority, perform consequential actions autonomously, learn invisibly, spend, sign, merge, or touch Breaker.
