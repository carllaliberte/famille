# ACORN — OPERATIONAL SELF-MODEL

Contract: `acorn.operational-self-model.v1`

This integrates Acorn's existing self-model/metacognition with measured runtime evidence. It keeps a current model of capabilities, resources, intelligences, uncertainties, failures and evidence.

## Cycle

COLLECT → NORMALIZE → MEASURE → VERIFY → UPDATE → DIAGNOSE → EXPOSE LIMITS → IDENTIFY GAPS → REOBSERVE

The purpose is not to make Acorn believe it is capable. The purpose is to make capability claims traceable to evidence and to keep unknowns visible.

Missing capabilities and observed limitations become explicit re-observation targets. The model never grants authority and never executes an external effect.

**SELF-KNOWLEDGE ≠ AUTHORITY.**
**CAPABILITY ≠ AUTHORITY.**
