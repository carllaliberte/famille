# Expansion Evolution Compiler

Contract: `acorn.expansion-evolution-compiler.v1`.

Compiles the expanding search space into explicit, versionable evolution plans. It connects verified reuse paths, candidate dependencies, baselines and targets, then emits bounded simulation/test/measurement/verification plans.

This is deliberately not an execution engine. A compiled plan is not an authorization, an action, a LIVE claim, or proof of value. Only measured + verified evidence can make an expansion version-eligible.
