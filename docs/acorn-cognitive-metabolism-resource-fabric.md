# ACORN Cognitive Metabolism & Resource Fabric
Contract: `acorn.cognitive-metabolism-resource-fabric.v1`

## Purpose
Give the Cortex a measurable metabolism: know what cognitive resources exist, what a task requires, what capacity is available, what a plan costs, and what efficiency was actually observed.

Cycle:
**SENSE RESOURCES → MEASURE → BUDGET → ASSESS CAPACITY → RANK PLANS → RESERVE/EXECUTE THROUGH EXISTING GOVERNANCE → OBSERVE → MEASURE → VERIFY → LEARN EFFICIENCY → REOPTIMIZE**

This is a resource fabric, not a second economy, execution runtime, router, or authority system.

## Integration
- World Model supplies entities/resources.
- Dynamic Synaptic Fabric supplies routes and cognitive relationships.
- Cortex Mission/Action fabrics consume resource assessments.
- Existing Effect Governor and Execution Fabric remain the only consequential-effect boundary.
- Outcome Learning remains the canonical learning gate.

## Resource dimensions
TOKEN, COMPUTE, TIME, ENERGY, MEMORY, BANDWIDTH, MONEY, CAPACITY, UNKNOWN.

Unknown resources remain explicit gaps; absence is never treated as zero cost.

## Truth and boundaries
**CAPABILITY ≠ AUTHORITY**
**MEASUREMENT ≠ AUTHORIZATION**
**OPTIMIZATION ≠ SPENDING**
**DEFINED ≠ EXECUTED ≠ MEASURED ≠ LIVE VERIFIED**

No automatic authorization, spending, transfer, contract, merge, publication, or external effect.

## Evolution
Future measured providers may add real token/compute/energy/cost/latency/reliability data. New resource types and scoring dimensions are additive and observable. Efficiency learning requires measured + verified outcomes. The fabric may recommend a better allocation but cannot authorize the consequential action.

## Definition of done
Contract + runtime + integration boundaries + evidence/provenance fields + tests + CI + documentation + evolution hooks in one durable architectural branch.
