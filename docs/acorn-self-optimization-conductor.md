# ACORN — SELF-OPTIMIZATION CONDUCTOR

Contract: `acorn.self-optimization-conductor.v1`

This is the next integration step after the autonomous knowledge loop. Acorn can now compose what it has learned about knowledge gaps, outcomes, synapses and resources into bounded optimization candidates.

## Canonical loop

ASSESS → MEASURE → VERIFY → IDENTIFY GAPS → GENERATE OPTIONS → SCORE → SELECT → SIMULATE → RETEST → REVERIFY → ADOPT CANDIDATE → REOBSERVE

The conductor does not claim a global optimum. It creates candidates from existing measured/verified fabrics and requires validation before adoption.

## Self-optimization boundary

Acorn may propose how its cognition could improve. It may not silently change authority, execute external effects, spend money, authorize itself, or adopt an unverified change.

A candidate becomes an **ADOPTION_CANDIDATE** only after simulation, retest and reverification. Human authorization remains required for adoption where the existing governance requires it.

**SELF-OPTIMIZATION ≠ SELF-AUTHORIZATION.**

**CAPABILITY ≠ AUTHORITY.**
