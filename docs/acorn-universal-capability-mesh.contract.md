# Contract — acorn.universal-capability-mesh.v1

A Universal Capability Mesh MUST preserve identity/capability/authority separation; require evidence for qualification; scope routing by context; require measured+verified outcomes for learning; expose expiration/revocation; and delegate all consequential execution to existing governance.

Forbidden: authority escalation, auto-authorization, auto-execution, Breaker bypass, hidden learning, unverified LIVE state, parallel Cortex/runtime.
