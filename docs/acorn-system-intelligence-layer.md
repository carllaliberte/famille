# Acorn System Intelligence Layer

Contract: `acorn.system-intelligence-layer.v1`

The System Intelligence Layer turns the measured forest into a descriptive, evidence-aware system view. It does not create a second brain or an authority layer.

## Cycle

OBSERVE → MAP → DEPEND → TRACE → MEASURE → IDENTIFY GAPS → PRIORITIZE OBSERVATIONS → REOBSERVE

## Measures

- dependency depth and critical paths
- downstream blast radius
- capability reuse and underuse
- resource observations, cost and latency
- unsupported claims and evidence gaps
- candidate observations ranked by measured information gain, cost, risk and gap relevance

## Truth boundary

This is system intelligence, not system authority.

- CAPABILITY ≠ AUTHORITY
- measured ≠ LIVE
- prediction ≠ fact
- recommendation ≠ authorization
- candidate action ≠ executed action
- human authority remains Carl
- no automatic authorization, execution, spending, contracting, signing, publishing or merging

The layer must expose missing measurements instead of inventing completion.

## Integration

It consumes the semantic forest, proof/observability fabric, reliability fabric and system genome/closure outputs already present on main. It produces a compact snapshot and bounded observation/action candidates for the existing governance path.
