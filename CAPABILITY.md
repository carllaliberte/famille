# Global Capability Registry — Cortex memory of what exists

Acorn Cortex already routes intelligences and compute. This layer is the
**living map of capabilities** — not a vendor list, not a model catalog,
not a second brain.

```
HUMAN INTENT
  → ACORN CORTEX
  → GLOBAL CAPABILITY REGISTRY
  → DISCOVERY → MEASUREMENT → CAPABILITY GRAPH
  → SWARM COMPOSITION → COMPUTE FABRIC
  → EXECUTION → EVIDENCE → MEMORY → LEARNING
  → ∞

BREAKER = HUMAN = OUTSIDE THE LOOP
```

```
IDENTITY ≠ MODEL ≠ CHANNEL ≠ CAPABILITY ≠ AUTHORITY
CAPABILITY ≠ AUTHORITY
DEFINED ≠ EXECUTED · OBSERVED ≠ PROVEN · CONSENSUS ≠ TRUTH
MORE COMPUTE ≠ AUTOMATICALLY BETTER
```

This is **not** a 7th chantier, a second Cortex, a parallel mesh, or a
super-organism. The registry belongs to Cortex. A new capability is added
by discovery and measurement — the cognitive core does not change.

The inventory of Acorn's own scripts ([capability inventory](scripts/acorn-capability-inventory.mjs))
is a different object: lifecycle of *this repo's modules*. The Global
Capability Registry is the map of *the world Cortex can discover*.
Construction of a missing capability is a third object that is not a third
architecture: [self-build](scripts/acorn-self-build.mjs) detects a
`CAPABILITY_GAP`, runs the existing loop in a safe zone, and never treats a
gap as an existing capability. GAP DETECTED ≠ EXISTS. READY ≠ AUTHORIZED.

## Honest states

`DISCOVERED` `IDENTIFIED` `DESCRIBED` `AUTHENTICATED` `AVAILABLE`
`CONNECTED` `SANDBOXED` `MEASURED` `BENCHMARKED` `VERIFIED`
`EXECUTABLE` `SWARM_ELIGIBLE` `PROVEN` `DEGRADED` `EXPIRED`
`REVOKED` `HOLD_HUMAN` `FAILED` `UNKNOWN`

Forbidden without proof: `LIVE` `READY` `CERTIFIED` `SUPER_BRAIN` `CONSCIOUS`.

Documentation never mints LIVE. `AVAILABLE` is observed presence, never
a magic claim. Unmeasured documentation stays `DESCRIBED`.

## Routing

Ask **which capability is required**, never which provider to call.
Free-first ladder:

`FREE → OPEN_SOURCE → LOCAL → PUBLIC → ACADEMIC → FREE_CREDITS → LOW_COST → PAID`

Paid and unconnected stay `REQUIRES_HUMAN_AUTHORIZATION`.
Spending authority is human.

## Unknown

`UNKNOWN_CAPABILITY` `UNKNOWN_COMPUTE` `UNKNOWN_INTELLIGENCE`
`UNKNOWN_SENSOR` `UNKNOWN_MEMORY` `UNKNOWN_NETWORK`
`UNKNOWN_ALGORITHM` `UNKNOWN_PHYSICS` `UNKNOWN_INTERFACE`

Ingest: `DISCOVER → ISOLATE → CHARACTERIZE → MEASURE → CLASSIFY → TEST → INTEGRATE|REJECT`

Integration is always `HOLD_HUMAN`. Cortex is not rewritten.

## Breaker

The Breaker is not a capability, not a resource, not a provider.
It cannot be discovered, optimized, replaced, or reassigned.

`MERGE = CARL` · `AUTO_MERGE = FALSE` · `MAIN = REALITY`
